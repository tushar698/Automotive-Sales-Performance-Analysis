# 🚗 Automotive Sales Performance & Revenue Analysis — 2025

## 📌 Project Overview

This project analyzes automotive sales data for 2025 using
Microsoft Power BI.

The dashboard provides insights into revenue, sales quantity,
monthly performance, state-wise revenue, brand performance,
and customer-level revenue distribution.

The objective is to transform raw automotive sales data into
interactive visualizations that help users understand sales
performance and identify important business trends.

## 🎯 Project Objectives

- Analyze overall automotive sales performance.
- Track monthly revenue trends throughout 2025.
- Compare revenue across different states.
- Analyze vehicle brand performance.
- Understand customer-level revenue distribution.
- Present important business KPIs in an interactive dashboard.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query Editor
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
- Interactive Dashboard Design

## 📊 Dashboard Features

### 1. KPI Cards
- Total Quantity
- Total Revenue
- Total Price

### 2. Monthly Revenue Analysis
Visualizes revenue trends from January to December 2025
to identify monthly changes and performance patterns.

### 3. State-wise Revenue Analysis
Compares revenue across states, including Maharashtra,
Uttar Pradesh, Karnataka, Gujarat, Delhi, and Tamil Nadu.

### 4. Brand-wise Quantity Analysis
Displays the quantity distribution across:
- Mahindra
- Creta
- Swift
- Scorpio

### 5. Customer-level Revenue Analysis
Displays revenue associated with individual customer IDs
to support customer-level sales analysis.

### 6. Interactive Dashboard Navigation
Includes multiple report pages for exploring:
- Overview
- Sales Performance
- Vehicle Analysis
- Regional Sales
- Customer Insights

## 🧹 Data Preparation

Power Query Editor was used for data preparation and
transformation before building the dashboard.

The dataset contains fields such as:
- Customer ID
- Customer Name
- State
- Brand
- Quantity
- Price
- Date
- Revenue

## 📐 DAX & Measures

DAX was used to create and support calculations for
key performance indicators and sales analysis.

The dashboard presents measures such as total quantity,
total revenue, and total price.

## 💡 Business Insights

The dashboard helps users explore questions such as:

- Which states generate the highest revenue?
- How does revenue change from month to month?
- Which vehicle brands contribute the most to sales quantity?
- How is revenue distributed across customers?
- Which periods show stronger or weaker sales performance?

Specific conclusions should be drawn from the underlying
dataset and the relevant dashboard filters.
